01 / OVERVIEW

Product Vision

CodeMate accepts source code and optional compiler/runtime messages, orchestrating local or cloud LLMs to detect bugs, explain root causes, and provide verified safe fixes.

Core Architecture

Designed with a modular provider pipeline supporting local Ollama models (such as Qwen 2.5 Coder) and cloud inference. Features visual side-by-side diffing, defect severity classification, and instant Markdown report generation.
