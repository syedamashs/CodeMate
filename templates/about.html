CodeMate is a
reasoning surface.

An Assignment 1 prototype for making structured prompting visible, testable, and useful.

01 / BRIEF

Project goal

CodeMate accepts source code and an optional error message, then asks a code-capable language model to identify problems, explain them, and propose a correction.

Technical approach

Model providers are replaceable. The current flow uses structured few-shot prompting and a resilient JSON-plus-section parser. Demo Mode provides a clearly labelled offline syntax and risk scan when no API is configured.
